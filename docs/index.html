Project Overview

Creatinine-to-cystatin C discordance and adverse events in patients receiving platinum-based chemotherapy.

The project repeats the Jiaxuan analysis at two cohort levels off one pipeline: the entire cohort (N = 943, all tumour stages) and the Local/Early cohort (N = 322, advanced/metastatic patients excluded). Every exposure, model, table, figure and download is carried over unchanged at both levels; both use the newer 2022P001091 creatinine pull and carry the CKD / ESKD / AKI variable family ported from the ICI-CKD project.

Details
Entire cohort no stage filter — N = 943
Local/Early cohort tumor_stage == "Local/Early" (stage I–II / local / neoadjuvant) — N = 322
Excluded from the Local/Early pages tumor_stage == "Advanced/Metastatic" (stage III–IV) — 621 patients
Primary exposure egfr_diff_pct_per10 — eGFR difference (%) per 10-percentage-point decline
Follow-up AKI administratively censored at 365 days; CKD composite to the last creatinine
Modelled outcomes AKI within 1 year and the CKD composite only — Fine-Gray competing risks, death at any time as the competing event

Exclusion Flow

Inherited from the Jiaxuan pipeline:

  1. REDCap records restricted to EMPIs present in N=596 for tianqi.xlsx → 946
  2. Patients with no matching RPDR lab records excluded (2) → 944
  3. Missing baseline cystatin C (cys_c_baseline = NA) excluded
  4. Missing platinum group (platin_group = NA) excluded
  5. Record 911 dropped (all RPDR pre-baseline labs fall outside the 45-day window) → 943 = entire cohort
  6. tumor_stage != "Local/Early" excluded (621) → 322 = Local/Early cohort

ritu_data.qmd saves after both step 5 (ritu_full_master.rds) and step 6 (ritu_final_master.rds), so the two cohort levels come from one pipeline run and are identical in every variable definition.

What Changed Relative to the Jiaxuan Project

Four kinds of change, nothing else:

1. Cohort source. ritu_data.qmd applies the stage restriction and writes ritu_final_master.rds; the three analysis pages read that file.

2. tumor_stage dropped as a covariate. It is constant within this cohort, so it carries no information and would make the design matrix rank-deficient. It is removed from Table 1 and from the adjuster set of every Fine-Gray, cause-specific hazard, Cox PH and linear-subHR model.

3. Two covariate fixes on the AUC ≥ 3 page only. That subgroup’s filter empties the cancer_type_cat_7 “GI” level (0 of 143) and leaves steroids constant at 1 (all 143 received steroids). Together these made the design matrix rank-deficient — rank 19 of 21 — so cmprsk::crr failed for every outcome, including composite grade 2 AEs with 64 events, while the formula interface silently returned blank coefficient rows. droplevels() is re-applied after the cohort filter and steroids is dropped from that page’s adjuster sets (it stays as a descriptive Table 1 row). The whole and carboplatin cohorts are full rank throughout and keep the original adjuster set.

4. Sparse-outcome guards. Several outcomes have very few events in 322 patients (90-day death = 2). Each model helper is wrapped so that a model which cannot be estimated emits a short note instead of aborting the render. No model specification is altered.

Unchanged: primary and sensitivity exposures, the dose_discrep_per25increase predictor in the carboplatin pages, reference categories (sex = Female, ecog_score_cat2 = “0”), the competing-risks framework, eGFR capping rules, and the Word and PowerPoint downloads. Section numbering changed when the 90-day outcome models were removed — see RITU_PROJECT.md §2.12.

Power Caveats

Only two outcomes are modelled: AKI within 1 year and the CKD composite, both with Fine-Gray competing risks and death at any time as the competing event. The multivariable models carry roughly 20 covariate degrees of freedom against a conventional target of 10 events per covariate, so event counts decide what is readable:

Cohort AKI ≤ 1 yr events CKD composite events Verdict
Entire (943) 197 70 AKI comfortably powered; CKD composite over-parameterised
Local/Early (322) 51 26 both over-parameterised
Carboplatin (189) 23 11 both over-parameterised
Carbo AUC ≥ 3 (142) 12 7 not interpretable

Univariable columns remain readable throughout. The entire-cohort AKI model is the only one of the eight that meets the 10-events-per-covariate convention.

Long-Horizon Kidney Outcomes (CKD / ESKD / AKI)

ckd_composite uses ckd_incidence (> 25 %), not ckd_incidence_any. The progression definition now requires a further > 30 % drop; previously it counted anyone below 60 before and after, i.e. stable CKD, which is why that count fell from 61 to 8.

Delta eGFR vs Baseline at 90 / 180 / 365 Days

Change in creatinine eGFR from eGFR_CRE_baseline, using the creatinine closest to each mark and only when it falls within ± 45 days of it. Days run from baseline_sample_date. Built in Section 5.16b of Data Management and reported per cohort in §2.3 (whole, entire) and §3.3 (carboplatin pages). Descriptive only — not modelled.

Negative means decline, i.e. eGFR at the mark minus eGFR at baseline. This is the opposite sign to pct_drop in the pipeline.

Mark n (of 943) Δ eGFR, median [IQR] Δ eGFR %, median [IQR] Fell > 25 %
Day 90 876 (92.9 %) 1.0 [−6.4, 7.8] 1.1 [−7.5, 10.0] 56 (6.4 %)
Day 180 710 (75.3 %) −2.6 [−12.0, 4.2] −2.8 [−14.6, 5.5] 94 (13.2 %)
Day 365 489 (51.9 %) −6.7 [−15.4, 1.6] −7.8 [−18.5, 1.5] 75 (15.3 %)

Local/Early (322): day 90 n = 301, Δ 0.9 [−5.9, 7.2]; day 180 n = 244, Δ −2.2 [−12.7, 3.3]; day 365 n = 176, Δ −7.5 [−14.9, −0.3].

The two carboplatin cohorts decline less: carboplatin (189) Δ +2.0 at day 90 and −3.9 at day 365; AUC ≥ 3 (142) Δ +2.0 and −5.9.

Two things to read with it. The realized day is tight — median 86, 179 and 364 against nominal 90, 180 and 365 — so the window is doing its job rather than quietly shifting the timepoint. But coverage falls with time, from 93 % at day 90 to 52 % at day 365, because creatinine is drawn less often once treatment ends. The day-365 figures therefore describe the half of the cohort still being monitored a year out, who are not a random half.

The ± 45-day window matches the pipeline’s existing baseline-lab window (pre_CRE_45days) and is the widest that keeps the 90- and 180-day marks from drawing on the same measurement. Without any window every patient gets a value at every mark, but the closest creatinine to day 365 would be over 276 days away for a tenth of the cohort.

Competing-Risk Models (death competing)

Fine-Gray models for egfr_diff_pct_per10 are in §4.12–4.13 of the whole and entire pages and §5.12–5.13 of the carboplatin pages. These are the only two long-horizon outcomes modelled; the 90-day adverse-event and hospitalization outcomes are modelled with the 90-day competing event in §4 / §5.

The competing event is death at any time, death_days_any — death_90 is capped at 90 days and cannot place a death in time beyond day 90, so it cannot serve over a multi-year horizon. death_days_any is the union of the two sources that carry a death date: the RPDR Date_Of_Death when there is one, otherwise the REDCap last-follow-up date for a patient whose pt_status is “Dead”. The two do not nest — 27 REDCap deaths have no RPDR date and 7 RPDR-dated deaths are not flagged dead in REDCap — so the union gives 279 dated deaths in the entire cohort against 252 from RPDR alone, and 31 against 28 in Local/Early. Someone flagged deceased in RPDR with no date who is still alive in REDCap stays censored. Censoring is at the last creatinine.

Events / competing deaths: AKI 197 + 114 (entire), 51 + 8 (Local/Early); CKD composite 70 + 265 (entire), 26 + 28 (Local/Early). Only the entire-cohort AKI model is comfortably powered against ~21 covariates.

Broadening the competing event from the RPDR-only death_lt to death_days_any left the estimates almost untouched — they were 1.31 (1.18, 1.47) and 1.14 (1.00, 1.30) in the entire cohort, 1.13 (0.87, 1.46) and 1.56 (1.13, 2.14) in Local/Early — so the extra competing events confirm the earlier result rather than revising it.

All of the above are Table 1 rows on all three analysis pages, together with esrd_kt (ESRD / KT at or before baseline, n = 1), eGFR_CRE_baseline, ckd_stage_baseline and last_cre_days. They also keep a dedicated section — 2.2 on the whole-cohort page, 3.2 on the carboplatin pages — carrying the median time to each event, the length of creatinine follow-up, and the aki vs AKI_kdigo_90days cross-tabulation that Table 1 cannot show.

AKI and the CKD composite are now modelled with Fine-Gray competing risks (see below). The remaining kidney variables stay descriptive.

aki is a different variable from the existing AKI_g2_90days / AKI_kdigo_90days: it compares each creatinine against the patient’s own preceding 90-day median across the whole record, not against a fixed pre-baseline value inside 90 days. In the whole cohort they agree on 19 patients, aki alone flags 44, and AKI_kdigo_90days alone flags 14.

Data Sources

REDCap export CystatinCInPatientsO_DATA_2026-10-09_1107.csv (refreshed follow-up) Baseline, treatment, outcomes

The REDCap export was refreshed on 2026-10-09 with updated follow-up: median follow-up rose from 378 to 539 days, recorded deaths from 207 to 272, and one patient was reclassified Local/Early → Advanced/Metastatic (so the Local/Early cohort is 322, not 323). That export also carries name, mgh_mrn and dob columns, which are dropped at read time and never enter the dataset or this site.

The newer RPDR pull is a creatinine-only extract — it has no Dia or Med file and no HGB/PLT/ALB/GHBA1C — so it supplies creatinine and the original pull supplies everything else. Both cover the same 973 EMPIs over 1989–2026; the newer one has ~2,800 more creatinine values, which is what the longitudinal eGFR, CKD and AKI outcomes are built from.

Variable Description
baseline_cre_egfr CKD-EPI 2021 creatinine eGFR (mL/min/1.73m²)
ckd_epi_gfr_cre_cys CKD-EPI 2012 combined creatinine + cystatin C eGFR (mL/min/1.73m²)
ckd_epi_gfr_cre_cys_unindex Combined CKD-EPI eGFR adjusted for BSA (mL/min)
cockcroft Cockcroft-Gault creatinine clearance
ckd_stage_cre KDIGO G-stage from baseline_cre_egfr (G3a / G3b kept apart)
ckd_stage_cre_cys KDIGO G-stage from ckd_epi_gfr_cre_cys (G3a / G3b kept apart)

eGFR_CRE_d90 / _d180 / _d365 Creatinine eGFR from the creatinine closest to that day, within ± 45 days of it
cre_day_d90 / _d180 / _d365 The actual day of the creatinine used — lets the gap from the nominal mark be checked
delta_egfr_d90 / _d180 / _d365 eGFR at the mark − eGFR_CRE_baseline, mL/min/1.73m². Negative = decline
delta_egfr_pct_d90 / _d180 / _d365 The same change as a percentage of baseline. Negative = decline

Only ckd_epi_gfr_cre_cys_unindex is capped at 125 mL/min; the indexed value and cockcroft are uncapped. Uncapped values feed the eGFR difference; capped values feed the dose-discrepancy calculation.

Both CKD stage variables use the standard KDIGO G categories — G1 ≥ 90, G2 60–89, G3a 45–59, G3b 30–44, G4 15–29, G5 < 15 mL/min/1.73m² — and are built from the BSA-indexed eGFRs, the scale KDIGO staging is defined on. No patient in this cohort reaches G5, so that level is dropped rather than shown as an empty Table 1 row. They are descriptive Table 1 rows only; no model adjusts for them (the continuous eGFRs already appear in the adjuster sets).
