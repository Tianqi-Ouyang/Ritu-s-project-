Ritu Project — Local/Early Stage Cohort Summary

Author

Tianqi Ouyang

Published

July 29, 2026

Project Overview

Creatinine-to-cystatin C discordance and adverse events in patients receiving platinum-based chemotherapy, restricted to locally staged / early-stage disease.

This project repeats the Jiaxuan analysis on a single restricted cohort. Every exposure, model, table, figure and download is carried over unchanged; the only substantive difference is that all advanced/metastatic patients are excluded.

Details
Cohort restriction tumor_stage == "Local/Early" (stage I–II / local / neoadjuvant)
Excluded tumor_stage == "Advanced/Metastatic" (stage III–IV) — 620 patients
Primary exposure egfr_diff_pct_per10 — eGFR difference (%) per 10-percentage-point decline
Follow-up 90 days from baseline sample date
Framework Competing risks (death as competing event for non-fatal outcomes)
Parent project Jiaxuan project

Exclusion Flow

Inherited from the Jiaxuan pipeline, plus one new step:

  1. REDCap records restricted to EMPIs present in N=596 for tianqi.xlsx
  2. Patients with no matching RPDR lab records excluded
  3. Missing baseline cystatin C (cys_c_baseline = NA) excluded
  4. Missing platinum group (platin_group = NA) excluded
  5. Record 911 dropped (all RPDR pre-baseline labs fall outside the 45-day window)
  6. New — tumor_stage != "Local/Early" excluded (620 patients) → N = 323

What Changed Relative to the Jiaxuan Project

Four kinds of change, nothing else:

1. Cohort source. ritu_data.qmd applies the stage restriction and writes ritu_final_master.rds; the three analysis pages read that file.

2. tumor_stage dropped as a covariate. It is constant within this cohort, so it carries no information and would make the design matrix rank-deficient. It is removed from Table 1 and from the adjuster set of every Fine-Gray, cause-specific hazard, Cox PH and linear-subHR model.

3. Two covariate fixes on the AUC ≥ 3 page only. That subgroup’s filter empties the cancer_type_cat_7 “GI” level (0 of 143) and leaves steroids constant at 1 (all 143 received steroids). Together these made the design matrix rank-deficient — rank 19 of 21 — so cmprsk::crr failed for every outcome, including composite grade 2 AEs with 64 events, while the formula interface silently returned blank coefficient rows. droplevels() is re-applied after the cohort filter and steroids is dropped from that page’s adjuster sets (it stays as a descriptive Table 1 row). The whole and carboplatin cohorts are full rank throughout and keep the original adjuster set.

4. Sparse-outcome guards. Several outcomes have very few events in 323 patients (90-day death = 2). Each model helper is wrapped so that a model which cannot be estimated emits a short note instead of aborting the render. No model specification is altered.

Unchanged: primary and sensitivity exposures, the dose_discrep_per25increase predictor in the carboplatin pages, reference categories (sex = Female, ecog_score_cat2 = “0”), the competing-risks framework, Cox PH for 90-day death, eGFR capping rules, 2.5/97.5-percentile plot trimming, Word and PowerPoint downloads, and all section numbering.

Power Caveats

These follow arithmetically from the smaller cohort. The analyses are reported as specified; read the sparse ones with the event counts in view.

Outcome Events in 323 Multivariable estimate
Composite grade 2 AEs 149 adequately powered
Anemia grade 2 138 adequately powered
Overall hospitalization 68 borderline
Platinum-related hospitalization 46 over-parameterised
Composite grade 3 AEs 43 over-parameterised
Anemia grade 3 40 over-parameterised
Thrombocytopenia grade 2 37 over-parameterised

AKI grade 2 26 over-parameterised
Thrombocytopenia grade 3 9 not interpretable
Individual hospitalization reasons 5–25 not interpretable
90-day death 2 not estimable

The multivariable models carry roughly 20 covariate degrees of freedom against a conventional target of 10 events per covariate. Univariable columns remain readable throughout.

Two further consequences worth stating in any write-up:

  • 90-day mortality is 2/323 (0.6 %). Early-stage patients rarely die within 90 days of starting platinum — a finding in its own right, not just a limitation.
  • The competing-risks correction barely bites. With death nearly absent, Fine-Gray subdistribution hazards and cause-specific hazards are close to identical in this cohort.

Long-Horizon Kidney Outcomes (CKD / ESKD / AKI)

Ported from the ICI-CKD project, re-anchored to baseline_sample_date. These are the only outcomes in the project that are not censored at 90 days — a qualifying CKD episode must be sustained for ≥ 90 days, so they use the full length of RPDR creatinine follow-up (median 446 days, max 1167).

Outcome Definition n (%) of 323
aki CRE > 1.5 × median of prior 90 d, or ≥ 0.3 mg/dL above the prior-2-day low 63 (19.5 %)
ckd_incidence Sustained ≥ 90 d: pct_drop > 0.30 & eGFR < 60 & baseline eGFR ≥ 60 15 (4.6 %)
ckd_progression Sustained ≥ 90 d: eGFR < 60 & baseline eGFR < 60 20 (6.2 %)
eskd_defination_1 Sustained ≥ 90 d: eGFR < 10 1 (0.3 %)
esrd_kt_after_ici ESRD / KT / dialysis ICD code after baseline 1 (0.3 %)
eskd_composite esrd_kt_after_ici == 1 \| eskd_defination_1 == 1 1 (0.3 %)
ckd_composite eskd_composite == 1 \| ckd_incidence == 1 \| ckd_progression == 1 35 (10.8 %)

esrd_kt (ESRD / KT at or before baseline, n = 1) is a Table 1 row.

These are reported descriptively and are not in any Fine-Gray, cause-specific or Cox model — mixing a full-follow-up outcome into the 90-day competing-risks framework would need its own censoring and competing-event decisions.

aki is a different variable from the existing AKI_g2_90days / AKI_kdigo_90days: it compares each creatinine against the patient’s own preceding 90-day median across the whole record, not against a fixed pre-baseline value inside 90 days. In the whole cohort they agree on 19 patients, aki alone flags 44, and AKI_kdigo_90days alone flags 14.

The newer pull is a creatinine-only extract — it has no Dia or Med file and no HGB/PLT/ALB/GHBA1C — so it supplies creatinine and the original pull supplies everything else. Both cover the same 973 EMPIs over 1989–2026; the newer one has ~2,800 more creatinine values, which is what the longitudinal eGFR, CKD and AKI outcomes are built from.

Key Variables

Exposure

Variable Description
egfr_diff_pct 100 × (CKD-EPI Cr-Cys unindexed − Cockcroft-Gault) / Cockcroft-Gault
egfr_diff_pct_per10 Primary reporting scale: per 10-percentage-point decline
egfr_diff_pct_sens_per10 Sensitivity: CKD-EPI 2012 CysC vs CKD-EPI 2021 Cr, per 10 % decline
dose_discrep_per25increase Carboplatin dose discrepancy (actual − predicted mg) / 25

eGFR & Kidney Function

Variable Description
baseline_cre_egfr CKD-EPI 2021 creatinine eGFR (mL/min/1.73m²)
ckd_epi_gfr_cre_cys CKD-EPI 2012 combined creatinine + cystatin C eGFR (mL/min/1.73m²)
ckd_epi_gfr_cre_cys_unindex Combined CKD-EPI eGFR adjusted for BSA (mL/min)
cockcroft Cockcroft-Gault creatinine clearance
ckd_stage_cre KDIGO G-stage from baseline_cre_egfr
ckd_stage_cre_cys KDIGO G-stage from ckd_epi_gfr_cre_cys

Only ckd_epi_gfr_cre_cys_unindex is capped at 125 mL/min; the indexed value and cockcroft are uncapped. Uncapped values feed the eGFR difference; capped values feed the dose-discrepancy calculation.

Both CKD stage variables use the standard KDIGO G categories — G1 ≥ 90, G2 60–89, G3a 45–59, G3b 30–44, G4 15–29, G5 < 15 mL/min/1.73m² — and are built from the BSA-indexed eGFRs, the scale KDIGO staging is defined on. No patient in this cohort reaches G5, so that level is dropped rather than shown as an empty Table 1 row. They are descriptive Table 1 rows only; no model adjusts for them (the continuous eGFRs already appear in the adjuster sets).
